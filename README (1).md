# Рабочий IPTV-плейлист: Азербайджан + СНГ

## Как это устроено

- `build_playlist.py` — тянет актуальные каналы из открытого проекта
  [iptv-org](https://github.com/iptv-org/iptv), проверяет каждую ссылку
  многопоточно (реальный HTTP-запрос к потоку) и пишет в
  `cis_and_az_channels.m3u` только те каналы, которые прямо сейчас отвечают.
- `check_report.json` — подробный отчёт: сколько ссылок было, сколько
  живых/мёртвых, отдельно — что нашлось по запросу "Матч"/"Match".
- `.github/workflows/update-playlist.yml` — GitHub Action, которая каждый
  день в 06:00 UTC сама запускает скрипт и коммитит свежий плейлист.

## Запуск локально

```bash
pip install requests
python3 build_playlist.py
```

## Про Матч ТВ

Официальный "Матч ТВ" (эфирный федеральный канал) вне России почти всегда
закрыт гео-блоком и DRM — у него нет легального бесплатного открытого
потока. Скрипт ищет и проверяет все каналы линейки "Матч!" (Арена, Игра,
Страна, Боец, Ультра и т.п.), которые есть в открытых источниках, и берёт
только те, что реально отвечают на момент запуска. Если хочешь именно
основной канал — придётся подключать платную подписку/легальный
IPTV-сервис, который его транслирует; вставлять сюда "ссылку из интернета"
бессмысленно, она умрёт через несколько дней.

## Автообновление в плеере (Televizo / OTT Navigator / TiviMate)

1. Залей эту папку в свой репозиторий на GitHub (публичный или приватный —
   для публичного raw-ссылка будет доступна сразу).
2. GitHub Action будет каждый день обновлять `cis_and_az_channels.m3u` в
   репозитории.
3. В плеере (например Televizo) добавляй плейлист **не файлом**, а
   **ссылкой**:
   ```
   https://raw.githubusercontent.com/<твой-юзернейм>/<репозиторий>/main/cis_and_az_channels.m3u
   ```
4. В настройках плейлиста в Televizo включи "Автообновление" и укажи
   интервал (например, раз в 24 часа) — плеер сам будет перекачивать
   свежий файл по этой ссылке, ничего вручную обновлять не нужно.

Если у тебя не Televizo, а другое приложение — принцип тот же: любой
плеер, поддерживающий "плейлист по URL с автообновлением" (OTT Navigator,
TiviMate, IPTV Smarters), работает с этой raw-ссылкой одинаково.
